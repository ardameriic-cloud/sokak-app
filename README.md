# ⚡ SOKAK — Ekip İçi Anlık Sesli ve Yazılı İletişim

**SOKAK**, rekabetçi oyuncular için sıfır FPS kaybı hedefiyle tasarlanmış, `128kbps Stereo Opus CBR` ses motoruna, `1080p 60FPS` ekran paylaşımına, **Birlikte İzle** (`🍿 Sinema & Yayın`) sahnesine ve kalıcı kullanıcı hesaplarına sahip masaüstü iletişim platformudur.

---

## 🚀 Hızlı Başlangıç

```bash
npm install
npm run dev
```

## 📦 Kurulum Paketleri (`SOKAK-Setup.exe` & `SOKAK.dmg`)

```bash
# Windows 10/11 kurulum paketi
npm run build:win

# macOS kurulum paketi
npm run build:mac
```
